## Установка
Программа проверена на Linux.

1. Если не установлены **git**, **python** и **mysql**, то сначала установите их
```
sudo apt install git python3 mysql-server
```

2. Скачайте репозиторий командой
```
git clone git@github.com:gh-Neniy/food.git
```

3. Внутри папки `food` создайте виртуальное окружение и запустите его
```
python3 -m venv .venv
source .venv/bin/activate
```

4. Установите зависимости
```
pip install -r requirements.txt
```

5. Для добавления в PATH и настройки базы данных
```
.venv/bin/python install.py
sudo .venv/bin/python set_database.py
```

6. После этого перезапустите консоль, можно командой:
```
exec bash
```
И снова запустите виртуальное окружение:
```
source .venv/bin/activate
```
Также для работы программы нужны:
- API-ключ в **API_KEY** в `Details/AI.py` для Gemini API
- Cookie сайта 5ka.ru от браузера на основе chrome, которой хотя бы 3 дня (для перезаписи cookie можно использовать флаг -u или --update-cookie)

## Архитектура
- Получение оригинальной куки от браузера, которой хотя бы 3 дня (иначе 403)
- Загрузка всех категорий в каталоге, по ним загрузка всех уникальных id товаров
- Для каждого id: если его нет в базе или он не обновлялся больше недели, то докачиваются для него данные - название, состав и цена
- Составляется запрос (в нескольких частях)  
с отправлением списка собранных продуктов в формате [(название, состав, цена)] и отправляется через API Gemini
- Ответ выводится в консоль
