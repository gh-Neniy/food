## Установка
Программа работает на Linux и macOS.

1. Если не установлены **git** и **python**, то сначала установите их
```
sudo apt install git python3
```
Или на macOS:
```
brew install git python3
```

2. Скачайте репозиторий командой
```
git clone git@github.com:gh-Neniy/food.git
```

3. Внутри папки `food` создайте виртуальное окружение и запустите его
```
python3 -m venv .venv
source .venv/bin/activate
```

4. Установите зависимости
```
pip install .
```

5. Для добавления в PATH и настройки базы данных
```
.venv/bin/python install
```

6. После этого перезапустите консоль:
```
exec bash
```
7. Запустите виртуальное окружение:
```
source .venv/bin/activate
```

**Также для работы программы нужны:**
- **API_KEY** для Gemini API (хранится в `.env` как `API_KEY`)
- **COOKIE** сайта 5ka.ru от браузера на основе chrome (запрос к категории или любому продукту), которой хотя бы 3 дня (хранится в `.env` как `COOKIE`)
- **SHOP_ID** магазина 5ka.ru (хранится в `.env` как `SHOP_ID`)
- VPN для работы Gemini API

Программа запускается из консоли вот так:
```
food
```

Поддерживаемые флаги:
| Флаг     | Действие                                                |
|----------|---------------------------------------------------------|
| `-a`     | Запросить API ключ для Gemini и сохранить в `.env`      |
| `-c`     | Запросить новый cookie и сохранить в `.env`             |
| `-s`     | Запросить новый shop id и сохранить в `.env`            |
| `-h`     | Собрать только категеории без сладостей и снеков        |
| `--help` | Показать справку по флагам                              |

## Архитектура
- Собираются нужные категории в каталоге, по ним все уникальные продукты. В каждом продукте информация о его id, названии и текущей цене
- Если id нет в базе, то догружается для него состав
- Составляется запрос со списком собранных продуктов в формате [(название, состав, цена)] и отправляется через API Gemini
- Ответ выводится в консоль

## Примечания
- Нужно настроить использование платных моделей для API-ключа
- Важно, чтобы cookie было хотя бы 3 дня, иначе после 5-6 запросов приходит 403 forbidden
