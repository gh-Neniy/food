Внутри кода указан определенный магазин (5076). Его можно поменять на нужный

## Установка
Программа работает на Linux.

1. Если не установлены **git**, **python** и **mysql**, то сначала установите их
```
sudo apt install git python3 mysql-server
```

2. Скачайте репозиторий командой
```
git clone git@github.com:gh-Neniy/food.git
```

3. Внутри папки `food` создайте виртуальное окружение и запустите его
```
python3 -m venv .venv
source .venv/bin/activate
```

4. Установите зависимости
```
pip install -r requirements.txt
```

5. Для добавления в PATH и настройки базы данных
```
.venv/bin/python install.py
sudo .venv/bin/python set_database.py
```

6. После этого перезапустите консоль, можно командой:
```
exec bash
```
7. Запустите виртуальное окружение:
```
source .venv/bin/activate
```

**Также для работы программы нужны:**
- Cookie сайта 5ka.ru браузера на основе chrome от запроса к категории или любому продукту, которой хотя бы 3 дня  
(для перезаписи cookie можно использовать флаг -u или --update-cookie)
- **API_KEY** в `Details/AI.py` для Gemini API
- VPN для работы Gemini API

Программа запускается из консоли вот так:
```
food
```
Чтобы собрать только продукты без сладостей, снеков и всего такого, можно использовать флаг --healthy или -h
```
food -h
```

## Архитектура
- Собираются нужные категории в каталоге, по ним все уникальные продукты. В каждом продукте информация о его id, названии и текущей цене
- Если id нет в базе, то догружается для него состав
- Составляется запрос со списком собранных продуктов в формате [(id, название, состав, цена)] и отправляется через API Gemini частями (из-за ограничения на количество токенов за раз), ответ на каждую часть сохраняется. Затем составляется запрос из всех полученных ответов и из них выбирается то, что требуется по запросу
- Ответ выводится в консоль

## Примечания
- Важно, чтобы cookie было хотя бы 3 дня, иначе после 5-6 запросов приходит 403 forbidden
- Также пока перед запуском программы приходится обновлять сайт 5ka.ru, иначе также приходит 403 forbidden
