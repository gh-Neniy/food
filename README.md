sudo .venv/bin/python install.py - для настройки базы

Архитектура:
1) Получаю оригинальную куки от браузера
2) Получаю сначала список всех категорий в каталоге
3) Получаю id товаров из каждой категории, оставляю только уникальные id
4) Прохожусь по каждому id, если его нет в базе данных, то докачиваю для него данные:
название, состав, цену
5) Обрабатываю все товары в наличии
6) Составляю промт для Gemini в формате
"Мне нужно выбрать наиболее полезные продукты из каталога моего магазина: {(название, состав, цена)}"
7) Закидываю этот промт через api Gemini
8) Получаю ответ в виде python-списка товаров (несколько штук по запросу), из них уже выбираю в магазине
